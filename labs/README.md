# Labs

Small experiments that make a concept observable. Use `../templates/lab.md` and give each experiment its own folder. Keep commands reproducible and generated outputs small or ignored.

Possible future experiments, not assigned or completed:

- Compare query plans and performance with and without an index.
- Reproduce a transaction anomaly using concurrent clients.
- Simulate replication lag and observe stale reads.
- Deliver an event twice and examine duplicate handling.
